如何使用redir进行矿池转发？无抽水

2025-01-26

我们将用一个例子来说明。例如需要连接的矿池为：stratum+tcp://public-pool.io:21496

其中stratum+tcp://代表协议，还有一个比较流行的stratum+ssl://。目前bitdsk只支持前者，即tcp。

public-pool.io代表需要连接的矿池服务器地址

21496代表连接的端口。

对应的后台配置填写如下：

下面说明如何转发

1：您需要购买一台云服务器，最好是国外的可以正常访问的。推荐一个可以找到这些资源的 URL：Google 搜索：vpser
注意：您需要一些知识才能确保您可以管理和运行此云服务器

2：使用ssh软件登录云服务器，运行命令更新系统（这里以ubuntu/debian系统为例）

sudo apt-get update

3：更新完成后安装redir

sudo apt-get install redir

4：安装完成后配置redir

命令： sudo redir

eg：

sudo redir :2345 public-pool.io:21496

注：冒号和空格均为英文格式

5：修改bitdsk后台矿池配置。例如我购买的云服务器IP地址为：123.123.123.123

6: 保存并重启bitdsk
