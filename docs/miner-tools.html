Bitdsk Miner Management tools on PC

Windows batch manager for monitoring and upgrading several miners at once.
Every build, with file size and SHA256, is also listed in the firmware index. Requires miner firmware ≥ all_3.0.0.

What it does

  • Lists every miner on your network in one table — name, IP, hashrate, uptime, accepted shares, best share and firmware version.
  • Edit pool settings on a miner without opening its web UI in another tab.
  • Reboot a board remotely.
  • Works without internet — 1.0.2 bundles its resources.

Setup

  1. Unzip the release and open config.js.
  2. Add the IP address of every miner you want to manage.
  3. Start the manager. A row that does not answer shows as waiting… until the miner responds.
