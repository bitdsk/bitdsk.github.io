Which file do I need?
Most upgrades are the single .zip — upload it in the miner web UI under Settings → Firmware, and your settings are kept (on U1/U2 the CD KEY too). Rows marked Abandoned or Expired are kept for reference only — do not flash them. For a board that will not boot, use the browser flash tool instead.
