Moved · dedicated repository

The flasher now lives on its own site

S1, U1 and U2 are three different hardware designs, and their flash images are large. Keeping them next to the flasher keeps this archive light and lets the flashing page ship on its own schedule.

Nothing was lost. Browser flashing still works exactly the same way — Chrome or Edge on desktop, USB cable, Web Serial. No PHP, no server-side code, no installer. The page and the images simply moved to a separate repository.

Why a separate repository

What moved and what stayed

Moved to the flasher

  1. The flashing page itself, plus the Web Serial component (bundled locally, no CDN).
  2. Full flash images for S1, U1 and U2 — bootloader, partition table, NVS, app, OTA data.
  3. The manifest.json for each board that tells the flasher where to write.

Stayed in this archive

  1. All OTA .zip downloads for N5, N8 and legacy boards.
  2. U series OTA single image and UI theme backgrounds.
  3. Every guide, API reference and version comparison page.
